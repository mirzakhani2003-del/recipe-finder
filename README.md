# Recipe Finder 🍽️

A responsive recipe discovery application built with Next.js, TypeScript, and Tailwind CSS. Search for recipes, explore cooking instructions, and save your favorite meals in one place.

## Features

- 🔍 Search recipes by name or ingredients
- 🍴 Filter recipes by cuisine and diet
- ↕️ Sort recipes by cooking time and popularity
- 📄 Paginated recipe results
- 🥗 Detailed recipe pages with ingredients, instructions, and cooking times
- ❤️ Add and remove favorite recipes
- 🌙 Light and dark themes
- 📱 Responsive design for desktop and mobile
- ⏳ Loading skeletons and API error handling
- 🛡️ HTML sanitization for recipe descriptions

## Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Spoonacular API
- DOMPurify
- Lucide React

## Getting Started

1. Clone the repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Create a `.env.local` file in the project root and add your Spoonacular API key:

   ```env
   SPOONACULAR_API_KEY=your_api_key_here
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000).
